# Known Debts

Every known gap, shortcut or mismatch lives here until it is resolved. Each entry states its impact and the plan to resolve it.
Remove an entry in the same change that resolves it.

| Area         | Debt                                                                                                                                                                                                               | Impact                                                                                                                        | Resolution plan                                                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Toolchain    | Local Node is 22.16; jsdom 30 and size-limit 13 need Node ≥ 22.18/22.22, so they are pinned one major back.                                                                                                        | None functionally; slightly older test tooling.                                                                               | Upgrade local Node to the latest 22.x or 24 LTS, then bump jsdom and size-limit.                                                |
| Toolchain    | TypeScript is pinned to 6.0.x because typescript-eslint doesn't support TypeScript 7 yet.                                                                                                                          | We can't use the native TypeScript 7 compiler.                                                                                | Bump when typescript-eslint's peer range includes 7.x.                                                                          |
| Icons        | The footer Instagram glyph (`InstagramIcon`) comes from an unidentified icon set; its licence is unverified.                                                                                                       | Cannot confirm redistribution rights for one icon.                                                                            | Identify the source set, or replace it with a glyph from a licensed set, before release.                                        |
| Visual tests | Screenshot baselines exist only for the local platform (`__screenshots__/win32`); CI (Linux) skips `@visual` tests.                                                                                                | Storybook screenshots catch visual regressions on one platform only.                                                          | Generate Linux baselines in the pinned Playwright Docker image, commit them and drop `--grep-invert @visual` from CI.           |
| Contrast     | 28 of 61 text/background pairings in the default palette are below WCAG AA (`packages/tokens/reports/contrast-report.md`). Kept by O-04; the browser axe suite reports them as warnings instead of failing (D-19). | Small muted, chrome and soft-tone text is hard to read for low-vision users unless the consumer's theme overrides the tokens. | Phase 12 contrast review: darken the tokens involved or document the override per pairing, then make `color-contrast` blocking. |
| Editor       | The editor's content styles are covered by unit tests but not by a visual test of a real editor render.                                                                                                            | A styling regression inside the editing surface would only be caught by eye.                                                  | Add an editor story with representative content (headings, lists, table, image) and a visual snapshot of it.                    |
