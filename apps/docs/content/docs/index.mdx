description: Avero is an RTL-first, bidirectional React and Tailwind CSS v4 component library.
---

Avero reproduces a complete, production-tested design system as reusable React components.
Every component is built on Avero design tokens, works in right-to-left and left-to-right layouts,
and ships with accessible behaviour.
