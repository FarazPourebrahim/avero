## Usage

```tsx
<CtaBanner eyebrow="مأموریت ما" title="یادگیری بدون مرز، برای همه">
  هدف ما فقط برگزاری چند دوره نیست…
</CtaBanner>
```

The banner works as a statement on its own, without a button. An `actions` slot is there for
pages that need a call to action under the text.

## Anatomy

| Part    | Slot                             | Notes                                          |
| ------- | -------------------------------- | ---------------------------------------------- |
| Root    | `data-slot="cta-banner"`         | A `<section>` with the slate → indigo gradient |
| Glows   | `data-slot="glow-orbs"`          | Decorative, `aria-hidden`                      |
| Actions | `data-slot="cta-banner-actions"` | Rendered only when given                       |

## Composition

Built from `GlowOrbs` and `Eyebrow` (`onDark`). The content sits on `relative z-10` above the
glows, so the 48px blur never washes the text out — an ordering that is easy to lose when copying
the markup by hand.

## Accessibility

- The heading level is yours to set: a banner that closes a page usually follows an `h1` and an
  `h2`, so pass `titleAs` to fit it into your own outline.
- The glows are decorative and hidden; there is nothing to describe.
- The banner's text is white on a dark gradient, which clears AA comfortably at every size used
  here.

## Do and don't

- **Do** keep the paragraph to a few lines — it is justified, and long text turns into rivers.
- **Don't** place another dark surface directly against it; the gradient needs light around it.
