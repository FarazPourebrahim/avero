## Usage

```tsx
<SplitHero
  eyebrow="از سال ۱۴۰۰"
  note="داستان ما"
  title="جایی برای یادگیری ساده و لذت‌بخش"
  image="/illustrations/story.svg"
  imageAlt="تصویر معرفی"
  actions={<Button elevated>مشاهده دوره‌ها</Button>}
>
  <p>…</p>
  <p>…</p>
</SplitHero>
```

Body paragraphs are children rather than a single string, because a hero often runs to two or
three of them and each needs its own `<p>`. They inherit the justified 15px prose from the
wrapper, so plain `<p>` elements are all you pass.

Without `image` the text column takes the full width — the grid columns are only applied when
there is something to put beside it.

## Anatomy

| Part    | Slot                             | Notes                                 |
| ------- | -------------------------------- | ------------------------------------- |
| Root    | `data-slot="split-hero"`         | A `Card` with the soft ambient shadow |
| Body    | `data-slot="split-hero-body"`    | The paragraph stack                   |
| Actions | `data-slot="split-hero-actions"` | Buttons under the text                |

## Layout

Seven columns of text beside five of illustration from `lg` up, one column below it. The
illustration sits in its own gradient-tinted frame and scales slightly on hover.

## RTL and LTR

The text column uses the logical `text-start` rather than a physical alignment, so the hero reads
correctly in both directions with no change to how it looks in Persian.

## Do and don't

- **Do** give the illustration real alternative text when it carries meaning, and `""` when it
  is decoration.
- **Don't** put a second heading inside the body; the hero's title is the section's heading.
