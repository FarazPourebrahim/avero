## Variants

| Variant   | Use                  | Difference                                   |
| --------- | -------------------- | -------------------------------------------- |
| `listing` | Listing sidebars     | 12px radius, hidden below `md`               |
| `project` | Detail-page sidebars | 16px radius, a soft shadow, and a hover fade |

## Usage

```tsx
<PromoBanner href="/courses" image="/banners/courses.webp" label="دوره‌های تازه" />

<PromoBanner
  variant="project"
  href="/workshops"
  image="/banners/workshops.webp"
  label="ثبت‌نام در کارگاه"
  className="lg:sticky lg:top-4"
/>
```

Sticking the banner to the viewport is a placement decision, so it stays a class on the instance
rather than a prop.

## Height

The banner has no height of its own: it is as tall as its artwork is, at the sidebar's width. Size
the artwork itself, or add an `aspect-*` class if you want a fixed box.

## Accessibility

The artwork is the link's only content, so `label` is required: it fills both the link's accessible
name and the image's alternative text. Without it the link would be announced as just "link".

## Do and don't

- **Do** describe the destination in `label` — "ثبت‌نام در کارگاه", not "بنر".
- **Don't** put text in the artwork alone; it will not be read out, translated, or searchable.
