## Usage

```tsx
<FeatureGrid title="چرا دوره‌های ما متفاوت‌اند؟" icon={<SparklesIcon />}>
  <FeatureCard title="پرداخت امن و بدون دغدغه" description="…" tone="emerald" />
  <FeatureCard title="مدرس‌های باتجربه" description="…" tone="blue" />
  <FeatureCard title="گواهی پایان دوره" description="…" tone="purple" />
  <FeatureCard title="پشتیبانی همیشگی" description="…" tone="amber" />
</FeatureGrid>
```

The cards are children, not data: `FeatureCard` already exists as its own component, and a grid
that only accepted a fixed shape would rule out mixing in anything else.

## Columns

`columns` sets the count at the widest breakpoint. Every value starts at one column on a phone and
two on a tablet:

| `columns`     | sm  | lg  |
| ------------- | --- | --- |
| `2`           | 2   | 2   |
| `3`           | 2   | 3   |
| `4` (default) | 2   | 4   |

## Anatomy

| Part  | Slot                             | Notes                                   |
| ----- | -------------------------------- | --------------------------------------- |
| Root  | `data-slot="feature-grid"`       | A `<section>`                           |
| Title | `data-slot="section-header"`     | A `SectionHeader` in its `icon` variant |
| Items | `data-slot="feature-grid-items"` | The grid itself                         |

## Accessibility

The title renders as an `h3` by default; pass `titleAs` when your page nests differently. Without a
title the grid is a plain section — give it an `aria-label` if it needs to be a landmark.

## Do and don't

- **Do** keep the card count a multiple of the column count, so the last row is not ragged.
- **Don't** vary description lengths wildly — the cards stretch to the tallest in each row.
