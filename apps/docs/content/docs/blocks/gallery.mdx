Blocks are larger compositions built only from Avero components — no ad-hoc markup beyond layout.
They are domain-neutral and take all of their text through props or slots, so a block is a starting
point you fill with your own content rather than a finished screen.

Each entry below renders live. Switch direction with the control on any preview, read the source in
the **Code** tab, and open **Full page** to judge a block at real width without the documentation
chrome around it.
