## Anatomy

| Part | Slot                           | Notes                                       |
| ---- | ------------------------------ | ------------------------------------------- |
| Root | `data-slot="author-card"`      | A `Card` surface, centred                   |
| Role | `data-slot="author-card-role"` | The pill under the name; omitted when unset |
| Bio  | `data-slot="author-card-bio"`  | Clamped to four lines; omitted when unset   |

## Usage

The card sits in the article sidebar, above the related-post panel:

```tsx
<AuthorCard
  name="سارا محمدی"
  roleLabel="سردبیر وبلاگ"
  image="/authors/sara.jpg"
  bio="طراح محصول و علاقه‌مند به آموزش…"
/>
```

The role prop is called `roleLabel`, not `role`, so the native ARIA `role` attribute stays
available on the card.

## Composition

Built from `Card` (`surface` variant, `brand` elevation), `Avatar` (96px with a four-pixel
`gray-500/20` border) and `Heading` at the `card` scale.

The surface uses `shadow-brand-soft`, a 2%-alpha shadow that separates the card from the page
without lifting it into a floating panel.

## Accessibility

- The name is a real `h3`, so the card appears in the document outline between the article's
  headings and the related-post panel.
- Without an image the avatar falls back to the name's initials, announced as an image labelled
  with the author's name.
- The biography is clamped visually with `line-clamp-4`; the full text stays in the accessibility
  tree, so pass a biography that reads well when truncated.

## Do and don't

- **Do** keep the biography to a few sentences — it clamps at four lines.
- **Don't** wrap the card in a link; nothing in it is interactive.
