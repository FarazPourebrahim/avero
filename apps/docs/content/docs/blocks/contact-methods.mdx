## Usage

```tsx
<ContactMethods title="راه‌های ارتباط با پشتیبانی" description="…">
  <ContactMethod href="mailto:…" label="email:" value="…" external />
  <ContactMethod href="tel:…" label="phone:" value="…" />
  <ContactMethod
    href="https://t.me/…"
    label="telegram:"
    value="@…"
    icon={<TelegramIcon />}
    external
  />
</ContactMethods>
```

The chips are [`ContactMethod`](../components/meta) components, which already handle the parts
that are easy to get wrong: the value renders left-to-right in a monospace face even inside an RTL
page, and `external` adds `rel="noopener noreferrer"` along with the new tab.

## Anatomy

| Part     | Slot                               | Notes                             |
| -------- | ---------------------------------- | --------------------------------- |
| Root     | `data-slot="contact-methods"`      | A `<section>` on a `Card` surface |
| Channels | `data-slot="contact-methods-list"` | Wraps onto as many rows as needed |

## Accessibility

Each chip is a link whose accessible name is its label and value together — "email:
hello@example.com" — so the channel and the address are announced as one thing. Phone and email
links work on mobile without any script.

## Do and don't

- **Do** say in `description` what the channels are for and when to use them.
- **Don't** list a channel nobody monitors.
