## Anatomy

| Part  | Slot                               | Notes                               |
| ----- | ---------------------------------- | ----------------------------------- |
| Root  | `data-slot="post-list-item"`       | An `<li>`; place it inside a `<ul>` |
| Title | `data-slot="post-list-item-title"` | Clamped to two lines                |
| Meta  | `data-slot="post-list-item-meta"`  | Author and reading time             |

## Usage

The row renders an `<li>`, so wrap a group of them in a list, such as a "مقاله‌های مرتبط" panel:

```tsx
<ul className="space-y-4">
  <PostListItem title="…" href="…" author="سارا محمدی" readTime="5 دقیقه" />
</ul>
```

## Composition

Built from `Image` and the bundled `ClockSolidIcon`. The thumbnail is a fixed 64px square
(`size-16`) that fades slightly when the row is hovered, driven by the row's `group` class.

## Accessibility

- The whole row is one link named by the title, so screen-reader users hear the post name rather
  than "image, link, link".
- The thumbnail is decorative (`alt=""`) — the title already carries its meaning.
- The clock glyph is decorative; the reading time beside it is real text.

## Do and don't

- **Do** keep the list short — three related posts are plenty in a sidebar.
- **Don't** render it outside a list; an `<li>` needs a list parent.
