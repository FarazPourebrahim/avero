## Usage

```tsx
<WelcomeCard name={user.displayName} />

<WelcomeCard name={user.displayName}>امروز دو جلسه تازه در انتظار شماست</WelcomeCard>
```

`name` is filled into the `greeting` dictionary string — `"سلام {name} 👋"` in Persian,
`"Hello {name} 👋"` in English — so the sentence structure stays with the locale rather than being
built by string concatenation at the call site. Pass `greeting` to replace the whole line.

## Anatomy

| Part     | Slot                                | Notes                    |
| -------- | ----------------------------------- | ------------------------ |
| Root     | `data-slot="welcome-card"`          | A 16px-radius white card |
| Greeting | `data-slot="welcome-card-greeting"` | The bold first line      |

## Shadow

The card uses `shadow-brand-soft`, a 2%-alpha shadow that separates it from the page background
without lifting it visually.

## Do and don't

- **Do** pass the name you actually have; the greeting reads badly with an email address.
- **Don't** put controls in here — it is a greeting, and the shortcuts live in
  [QuickActions](./quick-actions).
