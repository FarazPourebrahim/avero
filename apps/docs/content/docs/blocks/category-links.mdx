## Usage

```tsx
<CategoryLinks
  title="دسته‌بندی‌های مرتبط"
  description="دسته‌بندی‌ها و زمینه‌های تخصصی مربوط به این آگهی"
  icon={<FolderTreeIcon />}
>
  {categories.map((category) => (
    <Chip key={category.slug} asChild variant="tag">
      <a href={category.href}>{category.name}</a>
    </Chip>
  ))}
</CategoryLinks>
```

The links are `Chip`s in their `tag` variant, rendered `asChild` around an anchor — that is the
reference's own markup, and it keeps the hover treatment on the whole chip rather than the text.

## Anatomy

| Part  | Slot                               | Notes                      |
| ----- | ---------------------------------- | -------------------------- |
| Root  | `data-slot="category-links"`       | Brings its own top divider |
| Items | `data-slot="category-links-items"` | The wrapping link row      |

The block closes the project description rather than sitting on its own card, so it carries a
divider instead of a surface.

## Do and don't

- **Do** link every chip somewhere — a category that goes nowhere is a label, not a link.
- **Don't** repeat the project's own tags here; these are categories, not skills.
