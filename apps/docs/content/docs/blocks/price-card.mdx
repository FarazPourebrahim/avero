## Usage

```tsx
<PriceCard amount={course.price} />

<PriceCard amount={session.price} label="قیمت هر جلسه">
  <Button block>ثبت‌نام در دوره</Button>
</PriceCard>
```

`amount` is a number, not a string: it is formatted with the active locale's digits and grouping,
so the same value renders "۴٬۵۰۰٬۰۰۰" in Persian and "4,500,000" in English. The caption and
currency both come from the dictionary.

Anything passed as children appears under the price — a sign-up button, or a note about
instalments. Leave it empty when a separate panel carries the action.

## Anatomy

| Part    | Slot                           | Notes                               |
| ------- | ------------------------------ | ----------------------------------- |
| Root    | `data-slot="price-card"`       | A `Card` surface                    |
| Caption | `data-slot="price-card-label"` | The small bold line above the price |
| Price   | `data-slot="price-tag"`        | `PriceTag` in its `display` variant |

## Do and don't

- **Do** pass the raw number and let the locale format it.
- **Don't** put a second price in the same card; the panel exists to make one number unmissable.
