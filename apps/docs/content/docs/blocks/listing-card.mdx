## Anatomy

| Part    | Slot                               | Notes                                           |
| ------- | ---------------------------------- | ----------------------------------------------- |
| Root    | `data-slot="listing-card"`         | `<article>`, full width                         |
| Surface | `data-slot="card"`                 | `Card` `variant="glass"`, rendered as the `<a>` |
| Title   | `data-slot="listing-card-title"`   | Clamped to 2 lines with a `min-h` so rows align |
| Excerpt | `data-slot="listing-card-excerpt"` | HTML stripped, clamped to 2 lines               |
| Author  | `data-slot="listing-card-author"`  | `Avatar size="xs"` (28px) plus the name         |

## Composition

The card is built only from Avero components — `Card`, `Image`, `Chip`, `Avatar`, `PriceTag` and
`MetaItem` — so a change to any of them flows through every listing automatically:

- the surface is `Card variant="glass" padding="none"`, a translucent card that turns solid white
  on hover;
- the category uses `Chip variant="category"`;
- the price uses `PriceTag variant="inline"`, which renders "از ۴٬۵۰۰٬۰۰۰ تومان".

## Excerpt handling

Excerpts are often stored as HTML, and rendering that as text would show the tags literally.
`ListingCard` runs the excerpt through `stripHtml`, which removes markup, decodes basic entities
and collapses whitespace:

```tsx
import { stripHtml } from "@avero/react";

stripHtml("<p>مبانی طراحی رابط کاربری</p>"); // "مبانی طراحی رابط کاربری"
```

To _render_ stored HTML rather than flatten it, use [RichContent](../components/rich-content),
which sanitizes it.

## Accessibility

- The whole card is a single link named by `title`, so the accessible name never becomes a wall of
  concatenated text.
- The author row is plain content rather than a nested link — a link inside a link is invalid — so
  the card stays one link target.
- The cover image is decorative (`alt=""`): its meaning is already carried by the title.

## Do and don't

- **Do** pass `excerpt` exactly as stored; stripping is handled for you.
- **Don't** place another link or button inside the card — the surface is already one link.
