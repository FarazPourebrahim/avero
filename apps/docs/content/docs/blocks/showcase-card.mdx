## Anatomy

| Part    | Slot                              | Notes                                           |
| ------- | --------------------------------- | ----------------------------------------------- |
| Root    | `data-slot="showcase-card"`       | `group` card; the cover zooms on hover          |
| Title   | `data-slot="showcase-card-title"` | Links when `href` is given; turns blue on hover |
| Tags    | `data-slot="showcase-card-tags"`  | `Chip variant="mini"` tags                      |
| Actions | —                                 | Like, share, and a `report` slot                |

## Composition

Built only from Avero components — `Image`, `Chip`, `Button` and `IconButton`:

- the cover uses `Image zoom="group"`, a 500ms `group-hover:scale-105` transition;
- the like control is `Button variant="soft" tone="slate" size="xs"`;
- the share control is `IconButton variant="soft" tone="slate"`.

`Button` has a `slate` tone that matches the one `IconButton` already has, so the block needs no
hand-written colours.

## The report slot

The report control is shared by several cards and pages, so it is its own block
([`ReportAction`](./report)) rather than part of this card. Pass it in:

```tsx
<ShowcaseCard title="…" report={<ReportAction onReport={…} />} />
```

## Accessibility

- The **title** carries the link, and the like, share and report buttons are its siblings.
  Nesting controls inside a link is invalid, so the card itself is never the link.
- The like control exposes `aria-pressed`, and both controls take their accessible names from the
  `like` and `share` dictionary entries.
- The cover image is decorative (`alt=""`); the title already carries its meaning.

## Do and don't

- **Do** pass `report` when the card appears in a public listing.
- **Don't** wrap the card in a link — the title is already the link target.
