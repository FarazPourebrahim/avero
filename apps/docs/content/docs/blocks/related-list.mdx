## Usage

```tsx
<RelatedList title="دوره‌های مرتبط" actions={<Link href="/courses">همه</Link>}>
  {courses.map((course) => (
    <RelatedItem
      key={course.id}
      title={course.title}
      href={`/courses/${course.slug}`}
      image={course.cover}
      price={course.price}
    />
  ))}
</RelatedList>
```

A row shows a price when given a number, and anything else through `meta` — "رایگان", a date, a
rating. `meta` wins when both are passed.

## Anatomy

| Part  | Slot                             | Notes                             |
| ----- | -------------------------------- | --------------------------------- |
| Root  | `data-slot="related-list"`       | A `<section>` on a `Card` surface |
| Items | `data-slot="related-list-items"` | The row stack                     |
| Row   | `data-slot="related-item"`       | One link: thumbnail, name, price  |

## Accessibility

The thumbnail is decorative (`alt=""`), so each row is announced by its name and price rather than
by an image filename — the whole row is one link, not three.

## Do and don't

- **Do** keep names short — they truncate to one line at the sidebar's width.
- **Don't** list more than a handful; this is a sidebar, not a search result page.
