## Examples

### Saying which kind of empty

"No results for this search" and "you have nothing here yet" are different states and need
different words. Give the second one an `action` that starts the thing that is missing.

<ComponentPreview name="empty-state/distinct" />

## Right-to-left

Everything is centred, so the layout is direction-agnostic; only the message changes.

## Composition

- `text` and `slate` are message-only; they ignore `icon`.
- `icon` is the "coming soon" chart placeholder; `circle` is the panel-with-no-data state.
- `action` takes a [Button](./button) that starts whatever is missing.

## Accessibility

- Say what is missing and what to do next. "داده‌ای برای نمایش وجود ندارد" beats "empty".
- Distinguish "no results for this filter" from "nothing here yet" — they need different actions.
- Icons are decorative; the message carries the meaning.

## Do and don't

- **Do** give every list, query and panel an empty state.
- **Don't** leave a bare container when a collection returns nothing.
