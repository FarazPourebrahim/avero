## Anatomy

| Part | Slot                                 | Notes                                                      |
| ---- | ------------------------------------ | ---------------------------------------------------------- |
| Root | `data-slot="segmented-control"`      | Radix ToggleGroup, `role="radiogroup"`                     |
| Item | `data-slot="segmented-control-item"` | `role="radio"`; the checked item is white with indigo text |

## Examples

Unlike a plain toggle group, a segment can't be deselected: clicking the selected segment keeps it selected.

### Controlled

Pass `value` with `onValueChange` when the selection drives something else on the page. A segment
cannot be deselected, so there is always exactly one answer.

<ComponentPreview name="segmented-control/controlled" />

## Right-to-left

Arrow keys follow reading direction: in RTL, <kbd>←</kbd> moves to the next segment.

## Composition

- Use `value` / `onValueChange` to switch the content below it (for example, which chart is shown).

## Accessibility

| Key                                 | Action                                           |
| ----------------------------------- | ------------------------------------------------ |
| <kbd>Tab</kbd>                      | Moves focus into and out of the group            |
| <kbd>←</kbd> / <kbd>→</kbd>         | Moves between segments (reading direction aware) |
| <kbd>Space</kbd> / <kbd>Enter</kbd> | Selects the focused segment                      |

## Theming

Uses `gray-100` for the track and `indigo-600` for the checked text.

## Do and don't

- **Do** keep it to two to four short options.
