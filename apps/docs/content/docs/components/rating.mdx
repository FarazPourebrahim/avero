## Anatomy

| Score | —                    | Formatted with the locale's digits, `0.00` style |

## Right-to-left

The star leads at the inline start. The score uses the locale's decimal separator: `۴٫۵۰` in
Persian, `4.50` in English.

## Composition

- Add chip styling through `className` when the rating sits in a row of stat chips.
- Pass `label` for a visible prefix like "امتیاز:"; the accessible name stays the dictionary string.

## Accessibility

- Exposed as a single `role="img"` labelled "امتیاز ۴٫۵۰" / "Rating 4.50", so the star is never
  read as decoration-plus-number.
- Override the wording with the provider's `dictionary.rating`.
