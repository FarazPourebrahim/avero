## Anatomy

| Part | Slot               | Notes                                   |
| ---- | ------------------ | --------------------------------------- |
| Root | `data-slot="chip"` | A `<span>`, or your link with `asChild` |

## Examples

### Links

`link`, `tag` (with a leading icon that turns blue on hover) and `footer` are meant for links.

<ComponentPreview name="chip/links" />

## Right-to-left

The `tag` variant's icon sits at the inline start in both directions.

## Composition

- Use `asChild` with your router's link component for navigation chips.
- For the `tag` variant, put the icon first; it's sized and colored automatically.

## Accessibility

- Static chips are plain text. Link chips keep the link's semantics and focus behavior.

## Do and don't

- **Do** use `asChild` + a real link whenever a chip navigates.
- **Don't** use chips for statuses; use a [Badge](./badge).
