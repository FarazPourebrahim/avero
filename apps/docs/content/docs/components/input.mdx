## Anatomy

| Part | Slot                | Notes                                       |
| ---- | ------------------- | ------------------------------------------- |
| Root | `data-slot="input"` | Native `<input>`; `type` defaults to `text` |

`outline` (the default) matches every other form control; `filter`, `soft` and `slate` are the
alternative treatments.

## Examples

### Variants

`outline` is the default and the standard form control: the same 12px corners, gray-300 border,
white ground and blue focus ring as [Select](./select), [Combobox](./combobox),
[DatePicker](./date-picker) and [TagInput](./tag-input), so a form made of mixed controls reads as
one. `filter` is the compact square box. `soft` and `slate` mirror the comment-box treatments of
[Textarea](./textarea).

<ComponentPreview name="input/variants" />

### Input types

The native `type` is untouched, so email, telephone and search inputs keep their keyboards and
autofill. Give a field whose value is always Latin — an address, a number — `dir="ltr"`.

<ComponentPreview name="input/types" />

### States

`aria-invalid` turns the border and focus ring red, `readOnly` keeps the value selectable, and
`disabled` dims the box and blocks interaction.

<ComponentPreview name="input/states" />

## Right-to-left

Text and placeholder follow the document direction. Pass `dir="ltr"` on fields that hold
left-to-right values such as emails, phone numbers or URLs.

## Composition

- Every input needs a label: a real `<label htmlFor>`, or `aria-label` when the design has none.
- Set `aria-invalid` while a field fails validation; the border and focus ring turn red.

## Accessibility

- Renders a plain `<input>`, so browser autofill, form validation and password managers work.
- `disabled` prevents input and dims the field; it is not a substitute for read-only.

## Theming

| Token                | Used by                       |
| -------------------- | ----------------------------- |
| `--color-gray-300`   | `outline` and `filter` border |
| `--color-blue-500`   | `outline` and `filter` focus  |
| `--color-red-500`    | Border while `aria-invalid`   |
| `--color-indigo-500` | `soft`/`slate` focus          |

## Do and don't

- **Do** keep one variant per form.
- **Don't** use placeholder text as the only label.
