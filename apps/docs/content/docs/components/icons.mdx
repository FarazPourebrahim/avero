Avero uses [Lucide](https://lucide.dev) for general icons. The glyphs below cover what Lucide doesn't — brand logos and a few solid shapes from Font Awesome Free 5 and Heroicons — bundled as components so they need no icon font.

## Anatomy

| Part | Slot               | Notes                                    |
| ---- | ------------------ | ---------------------------------------- |
| Root | `data-slot="icon"` | An inline `<svg>` sized `1em` by default |

## Examples

Create an icon from path data:

```tsx
const Square = createIcon("SquareIcon", {
  viewBox: "0 0 24 24",
  mode: "stroke",
  paths: ["M4 4h16v16H4z"],
});
```

## Right-to-left

Icons don't flip automatically. Add `ltr:-scale-x-100` (or `rtl:`) to direction-bearing icons.

## Composition

- Icons inherit `currentColor`; set the color with a text utility.

## Accessibility

- Icons are decorative (`aria-hidden`) unless you pass `title`, which makes them `role="img"` with that name.

## Theming

Icons use `currentColor`.

## Do and don't

- **Do** give standalone meaningful icons a `title`, or put them inside a labelled [IconButton](./icon-button).
