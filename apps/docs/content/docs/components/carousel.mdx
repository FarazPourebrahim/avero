## Anatomy

| Part                            | Slot                                                | Notes                                                         |
| ------------------------------- | --------------------------------------------------- | ------------------------------------------------------------- |
| Carousel                        | `data-slot="carousel"`                              | A labelled `<section>` with `aria-roledescription="carousel"` |
| CarouselViewport                | `data-slot="carousel-viewport"`                     | Clips the track; slides go directly inside                    |
| CarouselSlide                   | `data-slot="carousel-slide"`                        | 85% wide on mobile, half the track from `md`                  |
| CarouselPrevious / CarouselNext | `data-slot="carousel-previous"` / `"carousel-next"` | Circular buttons, disabled at the ends                        |
| CarouselDots                    | `data-slot="carousel-dots"`                         | One button per snap position                                  |

## Right-to-left

The carousel scrolls in reading direction (Embla's `direction` follows `AveroProvider`), the previous button points to the inline start, and arrow keys follow reading direction.

## Composition

- Put the previous/next buttons anywhere inside `Carousel`, for example next to a section heading.
- Change slide widths with `className` on `CarouselSlide` (e.g. `basis-full` for one slide per view).
- Pass Embla options through `opts`, and get the Embla API with `setApi` for custom controls.

## Accessibility

| Key                         | Action                                                                                |
| --------------------------- | ------------------------------------------------------------------------------------- |
| <kbd>Tab</kbd>              | Moves through the controls and slide content                                          |
| <kbd>←</kbd> / <kbd>→</kbd> | Scrolls to the next or previous slide (reading direction aware) while focus is inside |

- The carousel is a named region; slides are groups with `aria-roledescription="slide"`. Give each slide an `aria-label` such as "1 از 3".
- The current pagination dot has `aria-current="true"`.

## Theming

Dots use `indigo-500` / `gray-300`; pills use `indigo-600` / `slate-300`.

## Do and don't

- **Do** show part of the next slide (the default 85% width does) so users know they can swipe.
- **Don't** autoplay; moving content hurts accessibility.
