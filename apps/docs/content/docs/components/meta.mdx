## Anatomy

| Part          | Slot                         | Notes                                             |
| ------------- | ---------------------------- | ------------------------------------------------- |
| MetaBar       | `data-slot="meta-bar"`       | `panel`, `row` or `inline` container              |
| MetaItem      | `data-slot="meta-item"`      | `plain`, `compact`, `pill` or `chip`              |
| KeyValueRow   | `data-slot="key-value-row"`  | Label at the start, value (or link) at the end    |
| ContactMethod | `data-slot="contact-method"` | Anchor chip with a monospace, left-to-right value |

## Right-to-left

Icons lead at the inline start and values follow. Contact values — emails, phone numbers, URLs —
stay `dir="ltr"` inside RTL text so their punctuation doesn't reorder.

## Composition

- `MetaBar` only lays out its children; mix item variants inside it freely.
- Pass any icon element; the components size `pill` and `chip` icons for you.

## Accessibility

- `ContactMethod` with `external` sets `target="_blank"` and `rel="noopener noreferrer"`.
- Keep labels ("انتشار:", "email:") as real text so the value is never announced without context.

## Theming

| Token                       | Used by                  |
| --------------------------- | ------------------------ |
| `--color-text-chrome`       | `KeyValueRow` text       |
| `--color-text-chrome-hover` | `KeyValueRow` link hover |
| `--text-sm-plus`            | `MetaBar` row variant    |

## Do and don't

- **Do** keep one `MetaBar` per block of metadata.
- **Don't** put interactive controls inside `MetaItem`; use `Chip` or `Button`.
