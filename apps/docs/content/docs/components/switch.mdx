## Anatomy

| Part  | Slot                       | Notes                                    |
| ----- | -------------------------- | ---------------------------------------- |
| Root  | `data-slot="switch"`       | Radix Switch, a `<button role="switch">` |
| Thumb | `data-slot="switch-thumb"` | Slides toward the inline end when on     |

`data-state` is `checked` or `unchecked` on both parts.

The track is 44×24 with a 2px outline, on the soft palette [Checkbox](./checkbox) and
[RadioGroup](./radio-group) share: a white track with a gray thumb while off, and a blue tint with a
blue thumb once on. Pressing shrinks it slightly, like a [Button](./button).

`SwitchCard` puts a switch in a settings row:

| Part        | Slot                                  | Notes                                           |
| ----------- | ------------------------------------- | ----------------------------------------------- |
| Card        | `data-slot="switch-card"`             | A `<label>`: the whole card toggles the switch  |
| Title       | `data-slot="switch-card-title"`       | Names the switch through `aria-labelledby`      |
| Description | `data-slot="switch-card-description"` | Describes the switch through `aria-describedby` |

## Examples

### Controlled

Pass `checked` with `onCheckedChange` when one setting governs another, so both are driven from the
same state.

<ComponentPreview name="switch/controlled" />

### Settings cards

`SwitchCard` presents a setting as a bordered row: the title and description at the inline start,
the switch at the inline end. The whole card toggles the switch, and it takes a soft blue tint while
on. Use it for settings pages where each option needs a line of explanation.

## Right-to-left

The thumb starts at the inline start and slides toward the inline end: right to left in Persian,
left to right in English. Switch the preview direction to compare.

## Composition

- Label it with a `<label htmlFor>` or [`Field`](./field); a description in `Field` is announced
  with the switch.
- `SwitchCard` takes every `Switch` prop and forwards its ref to the switch, so it works in a form
  and inside `FieldControl` exactly as `Switch` does. `className` styles the card;
  `switchClassName` styles the switch.
- Inside a `<form>`, a hidden native checkbox submits `on` under the switch's `name`.

## Accessibility

| Key                                 | Action                    |
| ----------------------------------- | ------------------------- |
| <kbd>Tab</kbd>                      | Moves focus to the switch |
| <kbd>Space</kbd> / <kbd>Enter</kbd> | Turns it on or off        |

- The state is exposed as `aria-checked`.
- A card's title is the switch's accessible name and its description the accessible description.
- **Contrast trade-off.** The off outline is `gray-300` (1.47:1 on white) and the off thumb
  `gray-400` (2.6:1), below the 3:1 WCAG asks of controls — the same deliberate choice as
  [Checkbox](./checkbox), recorded in `docs/known-debts.md`. The thumb's position also carries the
  state. Where strict AA matters, pass `className="border-gray-500/80"`. The on state passes: the
  thumb is 4.82:1 on its tinted track.

| `--color-gray-200` | `SwitchCard` resting border          |

## Do and don't

- **Do** apply the setting as soon as the switch changes.
- **Don't** use a switch inside a form that only takes effect on submit; use a [Checkbox](./checkbox).
