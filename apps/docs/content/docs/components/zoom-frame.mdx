## Anatomy

| Part    | Slot                             | Notes                                          |
| ------- | -------------------------------- | ---------------------------------------------- |
| Root    | `data-slot="zoom-frame"`         | `<button type="button">`, `cursor-zoom-in`     |
| Overlay | `data-slot="zoom-frame-overlay"` | Dims on hover and focus; not interactive       |
| Pill    | —                                | Slides in with the zoom icon and the hint text |

## Examples

### Hint text

The pill appears on hover and on keyboard focus. `hint` replaces the dictionary's wording when the
frame opens something more specific than an image.

<ComponentPreview name="zoom-frame/hint" />

## Right-to-left

The pill is centred and the icon leads at the inline start, so the layout is direction-agnostic.

## Composition

- Put your `<img>` (or the [Image](./image) component) inside; any nested image gets the hover scale.
- Open your lightbox from `onClick`; `ZoomFrame` only provides the affordance.

## Accessibility

- A real button, so it is focusable and activates with Enter and Space.
- The hint text is part of the accessible name, alongside the image's `alt`.
- The dim and pill also appear on keyboard focus, not only on hover.

## Do and don't

- **Do** give the image a meaningful `alt`; it names the button.
- **Don't** nest another interactive element inside the frame.
