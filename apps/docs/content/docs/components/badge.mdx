## Right-to-left

Badges are inline-flex with logical gaps, so icons stay before the text in both directions.

## Composition

- Place an icon before the text; size it with `size-3.5` or `size-4`.
- Adjust padding with `className` (e.g. the reference's `py-1` capacity badge).

## Accessibility

- Badges are plain text, not interactive, and aren't focusable.
- Don't rely on color alone: the text itself must convey the status.
- `solid` danger (white on red-500) is below AA contrast for small text; see the [contrast report](https://github.com/FarazPourebrahim/avero/blob/dev/packages/tokens/reference/contrast-report.md).

## Theming

Uses the Tailwind palette (`green`, `red`, `indigo`, `emerald`, `amber`) and the `gradient-premium` / `gradient-label` utilities from `@avero/tokens/utilities.css`.

## Do and don't

- **Do** keep badge text to a word or two.
- **Don't** make a badge clickable; use a [Chip](./chip) link instead.
