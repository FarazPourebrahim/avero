## Anatomy

| Part     | Slot                 | Notes                                                    |
| -------- | -------------------- | -------------------------------------------------------- |
| Root     | `data-slot="avatar"` | Radix Avatar root                                        |
| Image    | —                    | Shown once loaded                                        |
| Fallback | —                    | Initials by default; `role="img"` with the name as label |

## Examples

### Fallback

Without an image, or when it fails, the initials of `name` are shown (Persian names included).

<ComponentPreview name="avatar/fallback" />

## Right-to-left

Initials take the first letter of the first and last word in reading order, in any script.

## Composition

- `size="3xl"` with `border="ring"` is the profile header avatar that overlaps the cover.
- Add hover effects to the image with `imageClassName`.

## Accessibility

- The image uses `name` as its alternative text; the fallback carries the same name as its label.

## Theming

Uses `slate-200` for the fallback background and `slate-600` for the initials.

## Do and don't

- **Do** always pass the person's real name, even when an image is present.
