## Anatomy

| Part     | Slot                         | Notes                                              |
| -------- | ---------------------------- | -------------------------------------------------- |
| Image    | `data-slot="image"`          | `loading="lazy"` and `decoding="async"` by default |
| Fallback | `data-slot="image-fallback"` | Replaces a broken image                            |
| Figure   | `data-slot="figure"`         | Clips zoom effects to its rounded corners          |

## Examples

### Card media and fallback

`zoom="group"` zooms when a parent with the `group` class is hovered; a broken image becomes a neutral block.

<ComponentPreview name="image/card-and-fallback" />

## Right-to-left

Images have no direction-specific styling.

## Composition

- Wrap zoomable images in `Figure` (or any `overflow-hidden` rounded box) so the zoom stays inside the corners.
- Pass `loading="eager"` for the main above-the-fold image.

## Accessibility

- `alt` is required. Use an empty string only for decorative images; the fallback then stays hidden too.
