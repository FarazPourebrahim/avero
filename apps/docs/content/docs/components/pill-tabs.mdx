## Anatomy

| Part     | Slot                    | Notes                                                            |
| -------- | ----------------------- | ---------------------------------------------------------------- |
| PillTabs | `data-slot="pill-tabs"` | A labelled `<nav>`; scrolls horizontally with a hidden scrollbar |
| PillTab  | `data-slot="pill-tab"`  | A link; `current` fills it blue                                  |

## Examples

On narrow screens the row scrolls horizontally, and the current tab is scrolled into view automatically without moving the page vertically.

### Icons, counts and overflow

Tabs scroll horizontally with a hidden scrollbar when they outgrow the row, and the current tab is
scrolled into view. Put the count in the label so it is read with the tab's name.

<ComponentPreview name="pill-tabs/counts" />

## Right-to-left

Tabs flow from the inline start; the scroll-into-view logic works in both directions.

## Composition

- Each tab is a page link. For in-page content switching, use [SegmentedControl](./segmented-control).
- Use `asChild` with your router's link.

## Accessibility

| Key              | Action                         |
| ---------------- | ------------------------------ |
| <kbd>Tab</kbd>   | Moves through the tabs         |
| <kbd>Enter</kbd> | Follows the focused tab's link |

- Rendered as navigation links with `aria-current="page"` on the current one, which suits page-level sections better than ARIA tabs.

## Theming

Uses `blue-600` for the current tab and `slate-50` / `slate-100` for idle tabs.

## Do and don't

- **Do** show counts in the label, for example "دوره‌ها (3)".
