## Composition

- Use it inside [StatCard](#), [FeatureCard](#) and [ActionTile](#) (data display components).
- The `gradient` variant's quick-action hover effect comes from the parent card.

## Accessibility

- The tile is decorative. Put the meaning in the adjacent text.

## Theming

`primary`, the default, follows the brand: `--color-primary` for the icon and gradient, with
`--color-primary-soft` (soft), `--color-primary-soft-hover` (muted) and `--color-primary-hover`
(gradient end). Every other `tone` is a fixed Tailwind palette family, so `blue` stays blue whatever
the brand is.

## Do and don't

- **Do** keep one tone per meaning across a screen (e.g. purple for certificates).
