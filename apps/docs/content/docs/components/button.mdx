## Anatomy

A single `<button>` (or, with `asChild`, your own element) with an optional leading spinner.

| Part    | Slot                         | Notes                               |
| ------- | ---------------------------- | ----------------------------------- |
| Root    | `data-slot="button"`         | `<button type="button">` by default |
| Spinner | `data-slot="button-spinner"` | Shown while `loading`               |

## Right-to-left

Buttons use logical spacing, so they mirror automatically. Flip direction-bearing icons with `ltr:-scale-x-100`,
as in the first example. Use the RTL/LTR switch above each preview to compare.

## Composition

- Put icons before or after the label as children; size them with `size-4`.
- Override any utility with `className`. It's merged with `cn()`, so `className="px-6"` replaces the default padding.
- Reuse the styles on other elements with the exported `buttonVariants()`.

## Accessibility

| Key                                 | Action                                                  |
| ----------------------------------- | ------------------------------------------------------- |
| <kbd>Tab</kbd>                      | Moves focus to the button; a visible focus ring appears |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates the button                                    |

- Renders a native `<button>` with `type="button"` by default, so it never submits forms by accident.
- `disabled` and `loading` remove the button from interaction; `loading` also sets `aria-busy="true"`.
- Icon-only buttons should use [`IconButton`](#), which requires an accessible label.

| `--color-primary` / `--color-primary-hover` | `primary`, `inverse`, focus ring |
| `--color-secondary`                         | `secondary`                      |
| `--color-warning` / `--color-warning-hover` | `warning`                        |
| `--color-surface-glass`                     | `inverse` hover                  |

## Do and don't

- **Do** use one `primary` button per section for the main action.
- **Do** use `soft` tones for secondary actions such as sharing or reporting.
- **Don't** use a `Button` for navigation without `asChild` and a real link.
- **Don't** put a `loading` button's only label inside the spinner; keep the text.
