## Anatomy

| Part | Slot                      | Notes                                                   |
| ---- | ------------------------- | ------------------------------------------------------- |
| Root | `data-slot="icon-button"` | `<button type="button">` with `aria-label` from `label` |
| Icon | —                         | Your icon, passed as children                           |

## Right-to-left

Icons that point somewhere (arrows, chevrons) should flip in LTR with `ltr:-scale-x-100`, as in the carousel example.

## Composition

- Size the icon inside, e.g. `size-5`; `social` and `tile` have fixed sizes.
- Use `asChild` to render a link, for example a social profile.

## Accessibility

| Key                                 | Action                    |
| ----------------------------------- | ------------------------- |
| <kbd>Tab</kbd>                      | Moves focus to the button |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates the button      |

- `label` is required and becomes the `aria-label`, so icon-only buttons always have an accessible name.
- Icons inside are decorative; Avero's bundled icons are `aria-hidden` by default.

| Token                                          | Used by                        |
| ---------------------------------------------- | ------------------------------ |
| `--color-surface-muted`                        | `tile` background              |
| `--color-icon-muted` / `--color-accent-social` | `tile` icon, resting and hover |

## Do and don't

- **Do** write a label that says what happens ("Share on Telegram"), not what the icon is.
- **Don't** use an `IconButton` when there is room for a text label; use [Button](./button).
