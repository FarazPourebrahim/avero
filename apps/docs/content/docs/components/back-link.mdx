## Anatomy

| Part  | Slot                    | Notes                                      |
| ----- | ----------------------- | ------------------------------------------ |
| Root  | `data-slot="back-link"` | A link with `href`, otherwise a button     |
| Arrow | —                       | Points to the inline start; flipped in LTR |
| Label | —                       | Defaults to the dictionary's `back` string |

## Examples

The three variants above are `text` for article pages, `soft` for detail pages with a card header, and `subtle` for returning to a list.

### As a button

Without `href` the component renders a `<button>`, for going back a step in a flow rather than to a
URL. The arrow still points against the reading direction.

<ComponentPreview name="back-link/actions" />

## Right-to-left

In RTL the arrow points right, toward where reading started; in LTR it points left. Switch the preview direction to compare.

## Composition

- Without `href`, pass `onClick` (for example `() => history.back()`).
- With a router, use `asChild` and put your link inside; provide the label as its content.

## Accessibility

| Key              | Action                                                  |
| ---------------- | ------------------------------------------------------- |
| <kbd>Tab</kbd>   | Moves focus to the control                              |
| <kbd>Enter</kbd> | Activates it (and <kbd>Space</kbd> for the button form) |

- The arrow is decorative; the visible label is the accessible name.
