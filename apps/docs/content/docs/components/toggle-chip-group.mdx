## Anatomy

| Part | Slot                            | Notes                                          |
| ---- | ------------------------------- | ---------------------------------------------- |
| Root | `data-slot="toggle-chip-group"` | Radix ToggleGroup (multiple), `role="toolbar"` |
| Chip | `data-slot="toggle-chip"`       | A toggle button with `aria-pressed`            |

## Examples

Pass each chip the color of the chart series it controls; selected chips fill with it.

### Controlled selection

Any number of chips can be pressed at once, including none. Hold the array yourself when the
selection filters a list.

<ComponentPreview name="toggle-chip-group/controlled" />

## Right-to-left

Arrow-key navigation follows reading direction.

## Composition

- Keep `value` in sync with which series your chart renders.

## Accessibility

| Key                                 | Action                                        |
| ----------------------------------- | --------------------------------------------- |
| <kbd>Tab</kbd>                      | Moves focus into and out of the toolbar       |
| <kbd>←</kbd> / <kbd>→</kbd>         | Moves between chips (reading direction aware) |
| <kbd>Space</kbd> / <kbd>Enter</kbd> | Toggles the focused chip                      |

- Color is not the only cue: each chip exposes its state with `aria-pressed`.

Each `ToggleChip` takes a required `value`, an optional `color` (any CSS color; defaults to `--color-primary`) and every native `<button>` attribute.

## Theming

Unselected chips use `gray-50` / `gray-400`. The selected fill comes from each chip's `color`.

## Do and don't

- **Don't** use very light colors for `color`; the chip text is white.
