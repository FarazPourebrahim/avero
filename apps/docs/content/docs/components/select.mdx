## Anatomy

| Part      | Slot                           | Notes                                         |
| --------- | ------------------------------ | --------------------------------------------- |
| Trigger   | `data-slot="select-trigger"`   | `role="combobox"`; chevron rotates when open  |
| Content   | `data-slot="select-content"`   | Portalled popper, matches the trigger's width |
| Item      | `data-slot="select-item"`      | Highlight on hover and keyboard focus         |
| Label     | `data-slot="select-label"`     | Group heading                                 |
| Separator | `data-slot="select-separator"` | Hairline between groups                       |

The trigger matches the other filter controls. The listbox takes its surface, shadow and layer
from the token system, so it sits consistently above cards and sticky headers.

## Right-to-left

Radix reads the direction from `AveroProvider`, so the listbox aligns and animates from the
correct side and type-ahead works in both directions.

## Composition

- `SelectValue` shows the chosen option; its `placeholder` renders while nothing is selected.
- Group options with `SelectGroup` + `SelectLabel`, and separate groups with `SelectSeparator`.
- For a plain list on touch devices, [NativeSelect](./native-select) is the better default.

## Accessibility

- Full combobox semantics from Radix: `aria-expanded`, active-descendant highlighting and
  type-ahead. Enter, Space and the arrow keys open the list; Escape closes it.
- A hidden native select keeps the value in real form submissions.

| ---------------------- | -------------- |
| `--color-gray-300`     | Trigger border |
| `--color-blue-500`     | Focus ring     |
| `--shadow-card-raised` | Listbox        |
| `--z-popover`          | Listbox layer  |

## Do and don't

- **Do** label the trigger; the placeholder is not a label.
- **Don't** nest interactive elements inside an item.
