## Anatomy

| Part           | Slot                          | Notes                                                    |
| -------------- | ----------------------------- | -------------------------------------------------------- |
| StatCard       | `data-slot="stat-card"`       | Label + icon tile, big value below                       |
| StatTile       | `data-slot="stat-tile"`       | Translucent icon tile, big value, small label            |
| StatStrip      | `data-slot="stat-strip"`      | White strip of tiles with blue accent bars on both edges |
| MiniStat       | `data-slot="mini-stat"`       | Centered label over a bold value                         |
| InfoRow        | `data-slot="info-row"`        | Tinted row with an icon tile                             |
| HighlightPanel | `data-slot="highlight-panel"` | Amber gradient panel for a headline figure               |

## Right-to-left

The strip's accent bars sit at the inline start and end; the highlight panel's gradient mirrors in LTR.

## Composition

- Format numbers with `useAveroFormatter()` so they follow the active digits.
- Put stat cards in a grid such as `grid-cols-2 sm:grid-cols-3 lg:grid-cols-5`, as on the dashboard.

## Accessibility

- These are presentational; make sure the label text explains the number.
- Icons are decorative.
