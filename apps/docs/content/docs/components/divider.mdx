## Examples

Horizontal dividers separate card sections; vertical ones separate inline items (they stretch to the row height).

## Right-to-left

Dividers have no direction-specific styling.

## Composition

- Add spacing with `className` (e.g. `my-4`).

## Accessibility

- Decorative by default (`role="none"`). Set `decorative={false}` when the divider separates meaningful groups; it then becomes a `separator` with `aria-orientation`.

Uses `gray-100`, `slate-100` and `gray-200` from the Tailwind palette.

## Do and don't

- **Do** prefer spacing over dividers where grouping is already clear.
