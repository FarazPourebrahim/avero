## Anatomy

| Part        | Slot                                  | Notes                                          |
| ----------- | ------------------------------------- | ---------------------------------------------- |
| Root        | `data-slot="site-header"`             | `banner` landmark, sticky at `top-12`, blurred |
| Navigation  | `data-slot="site-header-nav"`         | Hidden below `md`                              |
| Actions     | `data-slot="site-header-actions"`     | Avatar, dashboard link, call to action         |
| Menu button | `data-slot="site-header-menu-button"` | Shown below `md`                               |

## Right-to-left

Logo and navigation sit at the inline start, actions at the inline end, so the bar mirrors
automatically.

## Composition

- Everything is a slot, and the header holds no state — wrap `SiteHeaderMenuButton` in a
  [Drawer](./drawer) `DrawerTrigger` with `asChild` to open the mobile menu.
- Use [Link](./link)'s `nav` variant for the navigation items and set `aria-current="page"` on the
  active one.
- `sticky={false}` pins it in place, which is useful inside previews and embedded views.

## Accessibility

- Renders a `<header>`, giving the page its `banner` landmark, with a real `<nav>` inside.
- The menu button needs an accessible name (`aria-label`), since it holds only an icon.

## Do and don't

- **Do** keep the navigation short; the drawer carries the full menu on phones.
- **Don't** put the page title in the header; that belongs to the page.
