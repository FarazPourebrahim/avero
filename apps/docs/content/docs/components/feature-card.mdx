## Anatomy

| Part        | Slot                       | Notes                                              |
| ----------- | -------------------------- | -------------------------------------------------- |
| FeatureCard | `data-slot="feature-card"` | Icon tile, title (`h4` by default) and description |
| ActionTile  | `data-slot="action-tile"`  | A button with a gradient icon tile and a label     |

## Examples

### Quick actions

On hover the whole tile fills with its gradient, lifts slightly and the label turns white.

<ComponentPreview name="feature-card/actions" />

## Right-to-left

Both components are centered or start-aligned and mirror automatically.

## Composition

- Set `FeatureCard`'s `titleAs` to follow your page's heading outline.
- Use `ActionTile asChild` with a link when the action navigates.

## Accessibility

| Key                                 | Action                        |
| ----------------------------------- | ----------------------------- |
| <kbd>Tab</kbd>                      | Moves focus to an action tile |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates it                  |

- The action tile's label is its accessible name; the icon and the hover overlay are decorative.
