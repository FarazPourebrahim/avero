## Anatomy

| Part   | Slot                                  | Notes                                   |
| ------ | ------------------------------------- | --------------------------------------- |
| Root   | `data-slot="disabled-overlay"`        | Absolutely positioned, faint blur       |
| Reason | `data-slot="disabled-overlay-reason"` | Red pill by default, slate when neutral |

## Examples

### Tones and radius

`danger` states that something is closed for good, such as a full workshop; `neutral` is for a
not-yet state. Match `radius` to the card underneath so the cover's corners line up.

<ComponentPreview name="disabled-overlay/tones" />

## Right-to-left

The pill is centred, so the overlay reads the same in both directions.

## Composition

- Put it inside a `relative` container and match `radius` to that container's corners.
- To dim the card itself (`opacity-70 blur-[1px]`), apply that to the card, not the overlay, so
  the reason stays legible.
- Make the card genuinely inert: `aria-disabled`, `pointer-events-none` and no focusable children.

## Accessibility

- The reason is real text inside the overlay, so it is announced with the card.
- Blur alone is not a state: never rely on it to signal that something is unavailable.

| `--color-red-500` | `danger` pill |

## Do and don't

- **Do** state why — "ظرفیت تکمیل شد" tells the user more than a greyed-out card.
- **Don't** leave links inside a covered card focusable.
