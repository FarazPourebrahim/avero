## Anatomy

| Part     | Slot                             | Notes                                      |
| -------- | -------------------------------- | ------------------------------------------ |
| Root     | `data-slot="price-tag"`          | `display`, `inline` or `compact`           |
| Prefix   | `data-slot="price-tag-prefix"`   | "از" / "From", `inline` variant by default |
| Amount   | `data-slot="price-tag-amount"`   | Formatted with the locale's digits         |
| Currency | `data-slot="price-tag-currency"` | "تومان" / "Toman" by default               |

## Examples

### Variants

`display` is the large price on a detail page, `inline` the "from …" line in a card, and `compact`
the tight one for dense rows.

<ComponentPreview name="price-tag/variants" />

### Prefix and currency

`prefix` puts a word before the amount and `currency` replaces the dictionary's unit — or drops it
entirely when the number is not money.

<ComponentPreview name="price-tag/currency" />

## Right-to-left

The amount is formatted with `Intl`, so Persian locales get Persian digits and the `٬` separator
(`۲۰٬۰۰۰٬۰۰۰`) and English locales get `20,000,000`. Order follows the reading direction.

## Composition

- Wrap `display` in a card with its own label ("قیمت پایه دوره"), as [PriceCard](../blocks/price-card) does.
- `amountClassName` adjusts only the number, e.g. a smaller size inside a dense listing card.

## Accessibility

- The price is plain text, so it is announced with its currency; no extra ARIA is needed.
- Don't remove the currency: an amount alone is ambiguous.

## Theming

| Token                 | Used by                        |
| --------------------- | ------------------------------ |
| `--color-primary`     | `display` and `compact` amount |
| `--color-text-chrome` | `inline` text                  |
| `--text-sm-plus`      | `inline` size                  |

## Do and don't

- **Do** pass the raw number and let the component format it.
- **Don't** pre-format the amount into a string; that loses locale digits.
