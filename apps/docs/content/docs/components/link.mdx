## Right-to-left

Links are inline text. Flip direction-bearing icons (like the back arrow) with `ltr:-scale-x-100`.

## Composition

- Use `asChild` with your framework's link (`next/link`, React Router) to keep client-side navigation.
- `current` marks the active navigation item and colors it with the primary token.

## Accessibility

| Key              | Action                  |
| ---------------- | ----------------------- |
| <kbd>Tab</kbd>   | Moves focus to the link |
| <kbd>Enter</kbd> | Follows the link        |

- `current` sets `aria-current="page"`.
- `external` opens a new tab with `rel="noopener noreferrer"`; mention that it opens a new tab in the text if it's not obvious.
