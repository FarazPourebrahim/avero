## Anatomy

| Part           | Slot                          | Notes                                    |
| -------------- | ----------------------------- | ---------------------------------------- |
| VisuallyHidden | `data-slot="visually-hidden"` | A `sr-only` `<span>`                     |
| LiveRegion     | `data-slot="live-region"`     | A `sr-only` `status` (or `alert`) region |

## Examples

Press the button above: the new text is announced by screen readers through the live region.

## Right-to-left

Hidden content follows the surrounding direction.

## Composition

- Add context that sighted users get visually, e.g. `کپی لینک <VisuallyHidden>این مقاله</VisuallyHidden>`.
- Keep one `LiveRegion` mounted and change its text; mounting a new region each time may not be announced.

## Accessibility

- `LiveRegion` uses `aria-live="polite"` and `aria-atomic="true"`; `politeness="assertive"` uses `role="alert"` for urgent messages only.

## Theming

None.

## Do and don't

- **Don't** hide essential content that sighted users also need.
