## Anatomy

| Part    | Slot                  | Notes                                          |
| ------- | --------------------- | ---------------------------------------------- |
| Heading | `data-slot="heading"` | Picks `h1`–`h4` from `size` unless `as` is set |
| Text    | `data-slot="text"`    | A `<p>` by default                             |
| Eyebrow | `data-slot="eyebrow"` | Small uppercase label                          |

## Right-to-left

Text aligns to the inline start. The `lead` variant is justified.

## Composition

- Keep the visual `size` and the semantic level independent: use `as` to fix the outline without changing the look.

## Accessibility

- Choose `as` so heading levels don't skip in the page outline.

## Theming

Uses the Lahzeh font via `--font-sans` and the Tailwind type scale; `lead` uses the `text-md` (15px) token.

## Do and don't

- **Do** use one `h1` per page.
- **Don't** use headings just to make text bold.
