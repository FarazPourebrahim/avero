## Right-to-left

The percentage is formatted for the locale: `۸٪` in Persian, `8%` in English.

## Composition

- Place it at the end of a card row; it never shrinks, so the title truncates instead.

## Accessibility

- Percentage and caption are plain text and read together ("۸٪ تطابق").
- Don't rely on colour alone to convey a weak match.

## Do and don't

- **Do** pass the percentage as `0…100`; values outside are clamped.
- **Don't** show a match score without the caption; a bare number is meaningless.
