## Anatomy

| Part           | Slot                           | Notes                                  |
| -------------- | ------------------------------ | -------------------------------------- |
| SidebarNav     | `data-slot="sidebar-nav"`      | A labelled `<nav>` with a list         |
| SidebarNavItem | `data-slot="sidebar-nav-item"` | A link with `href`, otherwise a button |

## Examples

The current page is a filled primary pill; idle items tint on hover; `tone="danger"` is the logout action.

### Tones and actions

An item without `href` renders a button, which is what signing out needs. `tone="danger"` marks that
kind of destructive action.

<ComponentPreview name="sidebar-nav/tones" />

## Right-to-left

Icons sit at the inline start and the layout mirrors automatically.

## Composition

- Use `asChild` with your router's link; pass the icon and label inside it yourself in that case.
- The same items work inside a drawer for the mobile menu (see [Drawer](./drawer)).

## Accessibility

| Key              | Action                              |
| ---------------- | ----------------------------------- |
| <kbd>Tab</kbd>   | Moves through the items             |
| <kbd>Enter</kbd> | Follows the link or runs the action |

- `current` sets `aria-current="page"`; give the navigation a name with `aria-label`.
